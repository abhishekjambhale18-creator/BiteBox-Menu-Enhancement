> Enhanced Menu page for the BiteBox multi-page website with images, lists, and structured content.

---

### 📌 Project Overview
This lab focuses on improving the **Menu page** of the BiteBox website.  
New features like food images, dish descriptions, unordered lists for categories, and ordered lists for ordering steps have been added using pure HTML.

---

### ✨ What Was Added in Menu Page
- Food images (`img` tag)
- Dish names and descriptions
- Food Categories using Unordered List (`ul`)
- How to Place an Order using Ordered List (`ol`)
- Restaurant information using `span` tags
- Navigation links remain consistent across pages

---

### 📄 Pages Included

| Page    | File           | Description                                  |
|---------|----------------|----------------------------------------------|
| Home    | `index.html`   | Main page with full restaurant info          |
| Menu    | `menu.html`    | Enhanced menu with images, lists & categories|
| About   | `about.html`   | About Us page                                |
| Contact | `contact.html` | Contact information page                     |

---

### 🛠️ Skills Demonstrated
- Adding images using `img` tag
- Unordered Lists (`ul` / `li`)
- Ordered Lists (`ol` / `li`)
- Using `span` for inline text
- Multi-page navigation
- Content structuring

---

### 🚀 How to Run
1. Open the repository
2. Open `index.html` in any web browser
3. Go to the **Menu** page to see the enhancements
